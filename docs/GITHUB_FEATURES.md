# GitHub 工作台功能范围

## 仓库能力

- 仓库列表、搜索、公开/私有仓库元数据
- 仓库简介、语言、Topics、License、Star/Fork/Watch、默认分支
- 文件目录、文件预览、代码搜索、哈希和版本读取
- 分支、Tag、Commit、差异比较
- Issue、评论、标签、Pull Request、Review 和变更文件
- Actions、Workflow、Job、失败步骤、Artifact 和运行监控
- Workbench 分支、Pull Request 创建；合并必须由用户确认
- 多仓库审计、Fork/镜像/克隆识别和差异复用

## 仓库设置

新软件还需要支持读取和管理：

- 仓库可见性：公开、私有、组织内部（服务器支持时）
- Archived 状态
- 默认分支
- Issues、Projects、Wiki、Discussions 开关
- Actions 可用状态

## 可见性修改安全流程

可见性修改是高影响远程操作，必须遵循：

1. 读取当前设置；
2. 明确展示旧可见性和目标可见性；
3. 展示风险提示；
4. 用户主动点击确认；
5. 生成一次性 confirmation ID；
6. 执行远程变更；
7. 重新读取仓库设置核验；
8. 保存审计记录；
9. 失败时保留错误和未完成状态。

公开仓库前至少提示：

- 代码、Issue、PR、Wiki 和历史 Commit 可能对所有人可见；
- 仓库中的敏感信息无法因为改回私有而保证未被复制；
- 应先扫描 Token、Cookie、密钥、个人信息和内部地址；
- Git 历史中的旧敏感值也必须检查。

私有化前提示：

- 公开链接、Fork、依赖和协作者访问可能受影响；
- 外部用户和 CI 权限可能发生变化。

## 明确不包含

不提供 Token 生成页面。不把 Token 原文写入普通日志、模型上下文、通知、导出物或 Git 提交。
