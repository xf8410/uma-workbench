# 安全操作策略（不脱敏）

## 立即实施范围

### 允许自动执行的只读操作

- 本地文件读取和索引；
- APK、Split APK、XAPK 清单读取；
- IL2CPP 类、字段、方法搜索；
- SO `/health`、`/status` 和有限只读查询；
- GitHub 仓库、分支、提交、PR、CI 和 Release 查看；
- 原始协议、日志和诊断内容完整显示。

### 必须明确确认的操作

- 删除或安全清理；
- 覆盖文件；
- 清空捕获缓冲；
- 安装或部署 Hachimi/插件；
- GitHub 创建仓库、PR、合并、Workflow dispatch；
- 上传任何文件；
- 改变仓库可见性；
- 执行未知仓库脚本或未知二进制。

### 确认页面必须显示

- 操作类型；
- 本地来源；
- 远程目的地（若有）；
- 仓库可见性；
- 分支；
- 路径；
- 文件数量；
- 总字节数；
- 是否覆盖；
- 是否可回滚。

确认不触发脱敏、过滤、压缩语义或改写内容。

## 数据完整性

- 原文件以 SHA-256 标识；
- 导出后可重新计算 SHA-256；
- 上传前后记录 Blob/文件哈希；
- 原始文件与派生结果物理分层；
- 派生失败不得修改原始文件；
- 后台任务使用 checkpoint 和幂等键；
- 崩溃恢复后从已验证 checkpoint 继续。

## 插件安全

未知插件不被静默执行。界面显示：

- 文件名；
- SHA-256；
- ABI；
- 来源；
- 版本/Host API（若可读）；
- 是否已验证；
- 将被安装到哪里。

用户确认后可安装未知来源插件，但安装器和 Workbench不得假装它已受信任。
