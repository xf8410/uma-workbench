# UMA Workbench

Android 手机端中文 AI 研究与开发工作台。项目名称不使用 Agora，界面只支持简体中文和繁體中文。

## 目标能力

- 对话、Agent 任务、工具活动和历史日志
- 项目规则、记忆自动加载与可审计优先级
- 多仓库/归档资料审计，按仓库拆分子任务并去重
- SO、IL2CPP、数据库、Master、MetaMD5 和端点索引
- 多页面工作簿、原始文件、结构层和中文语义层
- 离线优先、本地任务队列、Wi-Fi 切换容错、断点续传
- Token/费用、证据链、版本状态和风险审计
- App 内 UMA 桌宠；不默认申请系统悬浮窗权限

## 实施原则

1. Android 主线程不执行大文件读取、解析、网络或解压。
2. 长任务必须持久化，可暂停、恢复、重试和取消。
3. 原始资料不丢；索引、语义和结论分层保存。
4. 多仓库结果必须保留来源、版本、提交和哈希。
5. 线索、推测和已确认事实不能混淆。
6. JNI/FFI 是窄边界，Rust panic 不得穿过 FFI。
7. 离线状态不是任务失败；网络恢复后按幂等键同步。

## 阶段

- v0：Android 工程、模块边界、持久化任务模型、离线队列和审计协议。
- v1：对话/日志/记忆、文件导入、仓库元数据和差异扫描。
- v2：SO/metadata/DB/Master/MetaMD5 索引及端点关联。
- v3：工作簿语义层、证据链、Agent 编排、Token/费用。
- v4：受控运行时观测、桌宠动画、性能与恢复测试。
